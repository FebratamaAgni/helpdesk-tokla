# Panduan Tambah Produk Secara Massal

Halaman ini menjelaskan tata cara menambahkan produk ke dalam sistem merchant secara massal menggunakan formulir Excel, baik untuk kategori Buku maupun Barang & Jasa.

---

## A. Tambah Produk Buku Secara Massal

### Langkah 1: Menuju Menu Tambah Produk

1. Masuk ke halaman **Dashboard** merchant Anda.
2. Pada menu navigasi sebelah kiri, klik **Produk** lalu pilih **Daftar Produk**.
3. Klik tombol **Produk Baru** di bagian kanan atas halaman.
4. Pada halaman berikutnya, klik tombol **Tambah Banyak Produk**.

### Langkah 2: Mengunduh Template dan Mengisi Data Buku

1. Pada pilihan Jenis Produk, pilih **Buku**.
2. Klik tombol **Formulir Buku** untuk mengunduh berkas template Excel.
3. Buka file Excel yang diunduh, lalu isi data sesuai tabel yang disediakan (isi kolom wajib, gunakan format angka tanpa titik/koma untuk stok dan berat).
4. _Catatan Penting_: Jangan melakukan copy-paste antar kolom agar format file tidak berubah. Penamaan file gambar di kolom excel harus sesuai dengan nama dan format gambar asli (misal: `buku1.jpg`).

### Langkah 3: Mengunggah Dokumen dan Menyimpan

1. Unggah file Excel formulir buku yang telah diisi ke kolom **Unggah File Excel** (Maksimal 60 item per file).
2. Unggah semua gambar produk yang sudah dikompres ke dalam satu file **ZIP** pada kolom **Upload Gambar Produk (ZIP)**.
3. Centang kotak **Checklist pernyataan penyedia** sebagai tanda persetujuan kualitas barang.
4. Klik tombol **Simpan**. Tunggu proses impor selesai hingga muncul notifikasi **"Semua produk berhasil diimpor!"**, lalu klik **Tutup**.

---

## B. Tambah Produk Barang & Jasa Secara Massal

### Langkah 1: Menuju Menu Tambah Produk

1. Buka menu **Produk** > **Daftar Produk** pada Dashboard Anda.
2. Klik tombol **Produk Baru**, lalu pilih **Tambah Banyak Produk**.

### Langkah 2: Mengunduh Template dan Mengisi Data Barang/Jasa

1. Pada pilihan Jenis Produk, centang **Barang & Jasa**.
2. Klik tombol **Formulir Barang & Jasa** untuk mengunduh berkas Excel.
3. _Tips_: Anda bisa klik tombol **Data Kategori Produk** atau **Kategori Pajak** untuk memeriksa jenis ID kategori dan jenis pajak yang sesuai dengan komoditas Anda.
4. Isi tabel formulir Excel dengan teliti dan jangan menyalin data secara sembarangan antar kolom agar format tidak rusak.

### Langkah 3: Mengunggah Dokumen dan Menyimpan

1. Unggah formulir Excel ke area yang disediakan (Maksimal 120 item per file untuk barang & jasa).
2. Masukkan seluruh file foto produk ke dalam satu file folder berformat **ZIP** (misalnya `barang.zip`), lalu unggah pada kolom gambar.
3. Centang **Checklist pernyataan penyedia**.
4. Klik **Simpan** dan tunggu hingga indikator menunjukkan **5 / 5 Selesai**. Klik **Tutup** untuk melihat produk baru Anda masuk ke dalam Daftar Produk.
